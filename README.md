# Brick LCD — Стройка

Мобильная веб-игра в стиле карманной монохромной LCD-консоли: падающие блоки на поле 10×20.

## Запуск
Откройте `index.html` в браузере. На телефоне выложите папку на любой статический хостинг
(например, GitHub Pages) и добавьте страницу на главный экран — она откроется как приложение.

## Управление
| Действие | Кнопка | Клавиатура |
|---|---|---|
| Влево / вправо | LEFT / RIGHT (удержание — автоповтор; нажимать можно в любом месте вокруг крестовины, вести пальцем, не отрывая) | ← → |
| Ускоренное падение | DOWN (удержание) | ↓ |
| Поворот | ROTATE или верхняя кнопка крестовины | Пробел / ↑ / X |
| Старт / пауза | S/P | Enter / P |
| Звук | SOUND | S |
| В меню | RESET | R |
| Включить / выключить | ON/OFF | — |

В меню: ◀ ▶ — скорость (1–10), ▲ ▼ — уровень (0–10, столько рядов «мусора» снизу на старте).

## Очки
1 ряд — 100, 2 — 300, 3 — 700, 4 — 1500 (+10% за каждую ступень скорости).
Каждые 20 рядов скорость сама растёт на 1 (до 10), с какой бы скорости вы ни начали — как в китайских Brick Game. Рекорд сохраняется на устройстве.

## Корпус
Приложение выглядит как карманная Brick Game 90-х во весь экран телефона: экран в рамке с «кирпичиками»,
литой перегиб, жёлтые кнопки. Кнопка **КОРПУС** открывает выбор корпуса
(чёрный, белый, красный, синий, жёлтый, прозрачный). Листать: стрелки ◀ ▶, свайп или LEFT / RIGHT;
выбрать — «ГОТОВО» или ROTATE. Игра на это время на паузе, строка состояния телефона окрашивается в цвет корпуса.
**ON/OFF** выключает консоль (экран гаснет); при включении на мгновение загораются все пиксели, затем заставка.
Для полного погружения добавьте страницу на экран «Домой» — она откроется без интерфейса браузера.
Новый корпус — блок `:root[data-skin=...]` в `skins.css` и строка в `SKINS` в `game.js`.

## Экран
Кнопка **ЭКРАН** в ряду над крестовиной:
- **ЭКРАН** — переключает схему экрана по кругу: «Как было» (чистая картинка), «Старый LCD», «Жёлто-зелёный», «Холодный серый».
  В «старых» схемах есть шлейф медленных пикселей, тень пикселей на подложке, полупрозрачные «чернила»,
  зерно подложки, затемнение к краям и звук пьезопищалки.

В «старых» схемах можно нажать пальцем прямо на экран: вокруг пальца расползается мягкое тёмное облако,
в нём проступают негорящие пиксели; после отпускания оно расплывается и тает, при ведении пальцем остаётся шлейф.

Новую схему добавить просто: допишите объект в массив `THEMES` в начале блока «Темы экрана» в `game.js`.
(Режим «садятся батарейки» и контрастность остались в коде — `FX.battery`, `FX.contrast`, — но кнопки для них пока убраны.)

## GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка с игрой, папка **/(root)** → Save.
Через минуту-две игра откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
Для приватного репозитория Pages доступен только на платном тарифе GitHub; иначе репозиторий нужно сделать публичным.
