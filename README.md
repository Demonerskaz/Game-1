# Brick LCD — Стройка

Мобильная веб-игра в стиле карманной монохромной LCD-консоли: падающие блоки на поле 10×20.

## Запуск
Откройте `index.html` в браузере. На телефоне выложите папку на любой статический хостинг
(например, GitHub Pages) и добавьте страницу на главный экран — она откроется как приложение.

## Управление
| Действие | Кнопка | Клавиатура |
|---|---|---|
| Влево / вправо | ◀ ▶ (удержание — автоповтор) | ← → |
| Ускоренное падение | ▼ (удержание) | ↓ |
| Поворот | ПОВОРОТ или ▲ | Пробел / ↑ / X |
| Старт / пауза | СТАРТ/ПАУЗА | Enter / P |
| Звук | ЗВУК | S |
| В меню | СБРОС | R |

В меню: ◀ ▶ — скорость (1–10), ▲ ▼ — уровень (0–10, столько рядов «мусора» снизу на старте).

## Очки
1 ряд — 100, 2 — 300, 3 — 700, 4 — 1500 (+10% за каждую ступень скорости).
Каждые 20 рядов скорость сама растёт на 1 (до 10), с какой бы скорости вы ни начали — как в китайских Brick Game. Рекорд сохраняется на устройстве.

## Экран
Маленькие кнопки над экраном:
- **ЭКРАН** — переключает схему экрана по кругу: «Как было» (чистая картинка), «Старый LCD», «Жёлто-зелёный», «Холодный серый».
  В «старых» схемах есть шлейф медленных пикселей, тень пикселей на подложке, полупрозрачные «чернила»,
  зерно подложки, блик стекла, затемнение к краям и звук пьезопищалки.
- **БАТ** — режим «садятся батарейки»: бледный экран, тихий хриплый звук.
- **◐** — колёсико контрастности: на максимуме сильнее проступают негорящие пиксели.
- **НАКЛОН** — эффект угла обзора: наклоните телефон: если смотреть снизу, экран контрастнее и ярче, сверху — выцветает, как настоящий LCD;
  а блик и тени сдвинутся. Положение в момент включения считается «ровным». Нужен датчик ориентации:
  на iPhone игра спросит разрешение, и работает это только на обычном сайте с HTTPS (например, GitHub Pages),
  а не внутри страницы claude.ai.

## GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка с игрой, папка **/(root)** → Save.
Через минуту-две игра откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
Для приватного репозитория Pages доступен только на платном тарифе GitHub; иначе репозиторий нужно сделать публичным.

В «старых» схемах можно нажать пальцем прямо на экран: под пальцем проступают негорящие пиксели
и остаётся лёгкое пятно, которое расходится после отпускания, как на настоящем LCD.

Новую схему добавить просто: допишите объект в массив `THEMES` в начале блока «Темы экрана» в `game.js`.
